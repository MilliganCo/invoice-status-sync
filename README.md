# Invoice Status Sync

> Public experimental source: see [PUBLICATION.md](PUBLICATION.md) for actual checks, known defects, restored modules and operational limits. Earlier audit decisions are historical.

Python-утилита для синхронизации Excel-инвойсов со статусным файлом. Скрипт автоматически находит рабочий лист, ищет нужные колонки, нормализует размеры и переносит данные по артикулам и инвойсам в итоговый статусный документ.

## Статус аудита

`invoice_sync.py` — актуальный сценарий. Старый дублирующий файл `invoice_sync_laststable.py` удалён из текущей ветки, чтобы в репозитории оставалась одна понятная версия.

Проект содержит внутреннюю Excel-логику и naming conventions. Публичная публикация возможна только после обезличивания примеров, удаления бизнес-названий и full-history secret/data scan.

## Что делает

- обрабатывает входящие `.xlsx`, `.xlsm` и `.xls` инвойсы;
- подбирает подходящий лист статусов по имени или по структуре заголовков;
- поддерживает режим наблюдения за папкой с антидубликатами и ожиданием стабилизации файла;
- умеет работать с объединёнными ячейками и формулами итогов;
- использует безопасные example paths в текущей конфигурации.

## Структура проекта

- `invoice_sync.py` — основной сценарий;
- `requirements.txt` — зависимости проекта.

## Запуск

```bash
pip install -r requirements.txt
python invoice_sync.py
```

Перед рабочим запуском настройте локальные директории в `CONFIG` или вынесите их в отдельный локальный конфиг, который не коммитится.
