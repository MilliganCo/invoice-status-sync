# Invoice Status Sync

## Описание

Утилита для синхронизации Excel-инвойсов со статусным файлом. Скрипт автоматически находит рабочий лист, ищет нужные колонки, нормализует размеры и переносит данные по артикулам и инвойсам в итоговый статусный документ.

## Что делает

- обрабатывает входящие `.xlsx`, `.xlsm` и `.xls` инвойсы;
- подбирает подходящий лист статусов по имени или по структуре заголовков;
- поддерживает режим наблюдения за папкой с антидубликатами и ожиданием стабилизации файла;
- умеет работать с объединёнными ячейками и формулами итогов.

## Структура проекта

- `invoice_sync.py` — основной актуальный сценарий;
- `invoice_sync_laststable.py` — альтернативная стабильная версия;
- `requirements.txt` — зависимости проекта.

## Запуск

```bash
pip install -r requirements.txt
python invoice_sync.py
```

Если проект используется в режиме наблюдения, сначала настройте рабочие директории в конфиге внутри скрипта или замените их на свои локальные пути.
